## How to Generate

### Trajectory and camera figures

```bash
conda activate vggt
python path_matters/trajectory/scripts/3D_hemisphere.py
# outputs hemisphere_orbit.png
```

### Results figures (from CSV)

Open `notebooks/exploration.ipynb` and run all cells.  The notebook reads
`results/metrics/reconstruction_results.csv` and generates all bar charts,
scatter plots, and comparison tables.

### RL training curves

In Isaac Lab after training:

```bash
tensorboard --logdir logs/
# Export scalars as CSV, then plot with notebooks/exploration.ipynb
```

## Style Guidelines

All figures use:
- Background: `#0D1B2A` (dark navy)
- Accent:     `#00B4D8` (cyan)
- Object:     `#FF6D00` (orange)
- Grid lines: `#1D3461`
- Font:       DejaVu Sans, size 9–12
- DPI:        150 (draft) / 300 (publication)

This matches the existing trajectory figures in `path_matters/trajectory/scripts/3D_hemisphere.py`.
